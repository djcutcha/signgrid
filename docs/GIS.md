# GIS: 用途地域(設置場所の区分)

`legal.judge` の `place`(設置場所の区分)に渡すため、住所 → 緯度経度 → 用途地域を引く。実装は `kanban_karte/geo/`。

## 出典

- **国土交通省「都市計画決定GISデータ 全国データダウンロードページ」**
  https://www.mlit.go.jp/toshi/tosiko/toshi_tosiko_tk_000087.html(同意画面) → ダウンロードページ
  https://www.mlit.go.jp/toshi/tosiko/toshi_tosiko_tk_000182.html
- 取得日: **2026-11-02**。データ作成年度 令和7年度(掲載自治体の一覧は 令和8年10月26日時点)。
- 取得したもの: シェープファイル形式の **埼玉県** と **東京都** の2ファイル(他県は取っていない)。
  - 埼玉県 `/toshi/tosiko/content/001752729.zip` 21.9 MB → 展開 55 MB(58 市町、`*_youto.shp` 58 本)
  - 東京都 `/toshi/tosiko/content/001752732.zip` 36.5 MB → 展開 74 MB(52 区市町村、`*_youto.shp` 52 本)
  - 置き場: `data/private/gis/`(未追跡。`raw/` に zip、`saitama/` `tokyo/` に展開)
- 用途地域は市区町村ごとの `<市区町村コード>_youto.shp`(ほかに防火・高度地区等のレイヤが同梱だが使わない)。
  属性 `YoutoName`(例 `第１種低層住居専用地域`)を使う。全 110 本・15,783 ポリゴン、名前は 12 種
  (田園住居地域は、この2県のデータには無い)。文字コードは UTF-8。
- 東京都・埼玉県とも、全市区町村が載っているわけではない(東京都は 52、埼玉県は 58 の自治体)。載っていない自治体の点は
  `no_data`(判定に区分を渡さない)。

## 使用許諾(ダウンロード前の同意画面の要点)

無償提供。次の条件に同意してダウンロードする(原文は上のページ)。

- 国土交通省都市局都市計画課が、市町村・都道府県のGISデータや総括図から整備したもの。
- **建築確認申請や不動産重要事項説明等の手続に用いることを保証しない。参考情報としての利用を想定。**
- 地区・地域の範囲は**概ねの位置**で、実際の都市計画の決定範囲と異なる場合がある。
- 掲載されていない都市計画決定がある。最新でないことがある。最新で正確な情報は各地方公共団体へ。
- 国・原典データの提供元の自治体は、利用による損害に責任を負わない。
- 問い合わせ: 国土交通省都市局都市計画課都市計画調査室。

→ 本リポジトリの用途地域の判定は**参考値**。許可の要否の確定には使わない(`docs/IMPACT.md` の『用途地域ベースの暫定』)。
データそのものは再配布しない(`data/private/` は未追跡)。

## 座標系

`.prj` は `GCS_JGD_2011`(JGD2011 の経緯度、度単位)。**変換は不要**:
国土地理院の住所検索 API の座標は世界測地系(日本測地系2011と WGS84 の差は実用上数cm〜数十cm)で、用途地域の境界
(概ね±数m以上の精度)に対して無視できる。ファイルの点は (経度, 緯度) の並び。

## 読み方

- `pyshp==3.0.3`(純 Python。`requirements.txt` に固定)。Shapefile の読み込みだけに使う。
  読み込みは 15,783 ポリゴンで約 0.4 秒。
- 点がどのポリゴンに入るかは自前の ray casting(`geo/zoning.py`)。ポリゴンは外周と穴を持つので、輪の向きに頼らず
  全輪に対する even-odd 規則で内外を決める。bbox で先に絞る。
- `YoutoName` の `第１種…` を `legal.schema.ZONE_VOCAB` の `第一種…` に直して `place` に渡す(語彙の対応は下記)。
- 結果の `status`: `zone`(用途地域に入った) / `outside`(その市区町村のデータはあるがどの用途地域にも入らない
  = 市街化調整区域など) / `no_data`(データを持たない市区町村、または市区町村が分からない)。
  さいたま市は区(11101〜11110)がまとまって `11100_さいたま市` の 1 ファイル。

## 区分の語彙の対応(`legal.judge` の place)

`judge(place=...)` は `permit_zone` / `prohibited_zone` / `許可区域` / `禁止区域` / **用途地域名(`ZONE_VOCAB`)** を受ける。
用途地域名を渡すと、judge が規則ファイルの `prohibited_zones.labels`(その条例が禁止地域とする区域名の一覧)と
照らして、禁止区域か許可区域かを決め、`zone_labels` で区域を限った基準(東京都・越谷市の商業系の壁面 等)も絞る。
GIS の名前はそのまま渡せる(正規化だけ)。

| 条例 | 用途地域から禁止区域になるもの(規則ファイルの labels のうち用途地域) |
|---|---|
| 東京都 | 第一種・第二種低層住居専用、第一種・第二種中高層住居専用、田園住居 |
| 埼玉県・越谷市・さいたま市 | 第一種・第二種低層住居専用(埼玉県は田園住居も) |

**禁止地域の判定は『用途地域ベースの暫定』**。条例の禁止地域は用途地域だけで決まらない
(風致地区・特別緑地保全地区・生産緑地地区・景観地区・文化財周辺・文教地区・自然公園・道路鉄道沿い 等)。これらは
今回の GIS では引いていないので、**未判定**。用途地域が住居系以外でも、実際は禁止区域に当たる点があり得る。
用途地域が取れた = 『許可区域』と確定したわけではない。

## 実データでの確認(2026-11-02)

役所の所在地を国土地理院の住所検索で座標化し、用途地域を引いた。

| 点 | 住所 | 緯度, 経度 | 市区町村(逆ジオコーダ) | 用途地域 |
|---|---|---|---|---|
| 越谷市役所 | 埼玉県越谷市越ヶ谷四丁目2-1 | 35.890392, 139.791306 | 11222 越谷市 | 第２種住居地域 → 第二種住居地域 |
| さいたま市役所 | 埼玉県さいたま市浦和区高砂三丁目15-1 | 35.857182, 139.650787 | 11107 さいたま市 浦和区 | 商業地域 |
| 東京都庁 | 東京都新宿区西新宿二丁目8-1 | 35.689629, 139.691772 | 13104 新宿区 | 商業地域 |

3点とも `zone` が返った(住所検索の title は丁目・番・号まで届いた精度)。
